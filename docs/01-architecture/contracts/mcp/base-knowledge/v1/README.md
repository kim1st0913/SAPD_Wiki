# MCP 基础知识库访问合同 v1

本合同落实业务决策：基础知识库是已经完成入库治理、允许 AI 使用的知识域。MCP 可以通过固定只读工具访问其中全部业务知识内容，不再以 `public_summary` 或来源敏感级别作为二次筛选条件。

合同同时保持以下硬边界：

- MCP 依赖图不连接用户数据库；
- 不打开源文件，不执行文件系统搜索；
- 不返回本机路径、内部数据库 ID、凭据、调试字段或用户内容；
- 不接受客户端 SQL，只执行仓库层预定义的参数化只读查询；
- 来源证据只从基础库已有 provenance 表投影，不包含原始文件正文。

`docs/01-architecture/contracts/mcp/v1/**` 保留为 M0-T synthetic 公开摘要验证合同，不再代表正式基础库的业务访问范围。
