## 2. 字段边界

### 2.1 主展示字段

主展示字段应来自业务投影字段，例如：

- 编码、名称、描述、分类、情景；
- 能力层级；
- 作用域；
- 安全技术服务；
- 安全技术模块；
- 安全技术措施；
- 信息化环境；
- 环境子类；
- 信息化对象；
- 关系数量。

### 2.2 来源证据字段

以下字段只进入 SourceEvidencePanel 或来源证据区，默认折叠：

- `sheet`
- `row`
- `column`
- `cell`
- `raw_value`
- `source_file`
- `import_id`
- `source_id`
- `source_ref`
- `source_label`

### 2.3 不应主展示字段

以下字段不得进入前端主表、矩阵、关系链、筛选主维度或摘要区：

- `sheet`
- `row`
- `column`
- `raw_value`
- `source_file`
- `import_id`
- `source_id`
- `source_ref`
- `source_label`
- `debug`
- `raw`
- `metadata`
- `intermediate`
- `generated_at`
- 派生的 `status` / `状态`
- 非原表字段的 `待补充` 统计摘要

## 3. 重点关系复核

| 关系 | 当前判断 | 后续动作 |
|---|---|---|
| 能力分类 -> L1 -> L2 -> 关注点 | 表达准确，属于能力维度基础树 | 用户确认排序和编码为最终口径 |
| 关注点 × 作用域 -> 安全技术服务 | 业务规则清楚：`/` 为无适用服务，非空服务应唯一 | 保持异常检测：同一关注点 + 同一作用域下多个非空服务需输出问题 |
| 安全技术服务 -> 安全技术模块 | 由安全技术模块清单提供 N:M 映射 | 用户已确认安全系统是安全技术模块的上级分类，系统/产品不作为能力/环境主链路 |
| 安全技术措施 -> 安全技术服务 | 已由 G 列分流和措施导出支持 | 前端展示需继续保持多值，不压成单值 |
| 安全技术措施 -> 作用域 | 已由映射表和导出支持 | 用户确认措施是否需要独立分类字段 |
| 安全技术措施 -> 信息化环境 / 信息化对象 | 当前通过作用域 / 对象映射派生展示 | 确认派生逻辑是否足够可靠，必要时后续 ETL 显式输出 |
| 信息化环境 -> 环境子类 -> 信息化对象 -> 安全作用域 | 表达基本准确但需前端层级修正 | `environment_segment` 已确认为正式层级，中文口径为“环境子类”；同名信息化对象可存在于多个类似环境，是正常业务逻辑 |
| 安全作用域 -> 安全技术服务 -> 安全技术模块/措施 | 表达基本准确 | 前端需区分模块与措施，不把二者混成同一业务对象 |

## 4. 已确认口径

1. `安全能力目录` 的层级、编码、排序是最终业务口径。
2. 前端一级页面“能力维度”后续应改名为“安全能力映射”。
3. `安全能力作用域目录` 已由用户修正原始数据并补充 `I-PE 物理环境`。
4. 作用域清单按原表字段展示；派生的“作用域类型”和“状态”不作为主表字段展示。
5. 多个页面中派生的 `状态` 字段和 `待补充` 统计摘要不作为主展示内容。
6. 信息化对象可出现在多个类似信息化环境中，例如远程接入和办公园区都可以有终端软件应用，这是正常业务逻辑。
7. `environment_segment` 确认为信息化环境树的正式层级，中文口径为“环境子类”；前端层级应调整为“信息化环境 -> 环境子类 -> 信息化对象 -> 安全作用域”。
8. `安全能力-安全技术服务` 保持 `/` 为无适用服务，并保留多服务异常检测。
9. 安全技术模块清单中，安全系统是多个安全技术模块的上级分类。
10. 产品字段表示对应产品名称，`我司无相关产品` 是正常值，表示没有相应产品可关联。
11. 作用域-服务-模块/措施连续映射中，前端需要显式标签区分“安全技术模块”和“安全技术措施”。

## 6. 当前展示修正建议

本轮不直接修改前端，只记录后续修正方向：

- 安全能力映射：当前基本准确，继续保留“当前关注点 × 作用域 -> 服务 -> 模块/措施”的表达，避免恢复线性链路；页面名称需从“能力维度”调整为“安全能力映射”。
- 信息化环境维度：当前基本准确，但需把 `environment_segment` 从辅助字段提升为正式层级“环境子类”，调整为“信息化环境 -> 环境子类 -> 信息化对象 -> 安全作用域”。
- 专项知识维护：作用域清单、技术模块清单、技术措施清单已具备第一阶段可用性；后续应按用户确认调整主列和详情字段。
- 全局字段展示：派生 `状态` 和非原表字段的 `待补充` 统计摘要不作为主展示内容。
- 技术模块 / 技术措施边界：当前数据契约已区分，后续前端展示应增加显式标签，避免把两者混成同一对象。
