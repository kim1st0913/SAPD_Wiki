## 7. 样例文件结论

| 结论项 | 当前判断 |
|---|---|
| V1 最适合先导入的文件类型 | Excel。它是主数据来源，结构最清晰，且包含主要查询关系。 |
| 第一批知识对象类型 | SourceFile、Capability、CapabilityFocusPoint、Scope、InformationObject、SecurityTechnicalService、SecurityTechnologyModule、SecuritySystem、Product、Process、Role、StandardFramework、StandardControl、DiagramView、UserGuideSection、Relation |
| 第一批必填字段 | 对象类型、名称、来源文件、来源位置、来源版本/hash、创建/导入时间；关系需要 source、target、relation_type、source_location |
| 第一批可选字段 | 定义/描述、分类、层级、标签、适用作用域、标准编号、产品映射、备注、原始值 |
| 第一批暂不处理内容 | PPT 精细版式还原、Draw.io 坐标和颜色语义、全部标准框架的深度归一化、自动覆盖人工修改 |
| 第一批导入建议 | 先做 Excel 的 5 个核心 Sheet：安全能力目录、安全能力作用域目录、安全能力-安全技术服务、安全技术模块清单、作用域-安全技术服务-安全技术模块映射。完整 26 个 Sheet 后续都要分批处理。 |
| 第一批展示建议 | PPT 后续单独建立使用说明页面；Draw.io 后续作为只读视图展示，不考虑编辑功能。 |
