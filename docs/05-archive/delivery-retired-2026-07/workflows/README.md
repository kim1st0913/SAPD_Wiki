# Retired public workflows

`build-windows-backend.yml` is the archived backend-only Windows workflow from the deleted `codex/windows-electron` branch flow.

It is intentionally outside `.github/workflows/` so GitHub Actions no longer presents it as a current manual build entry. The production Windows installer is built by the private `kim1st0913/SAPD_Wiki_Delivery_Private` workflows described in `docs/09-delivery/packaging-directory-map.md`.
