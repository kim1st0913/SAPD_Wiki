### 4.5 NIST SP 800-53 Rev.5

NIST 800-53 的未映射项需要分两层处理：

1. 父控制项已经映射的 enhancement，优先继承父控制项的候选关注点，并标记为候选关系。
2. 父控制项本身未映射，才单独进入人工确认。

用户已接受后续导出规则：如果 `NIST 800-53 Rev.5` enhancement 的父控制项已经被映射，则 enhancement 先继承父控制项映射，并把 `confidence` 标为 `candidate`，避免把未覆盖项全部人工散挂。
