## OI-198：导入审批缺少幂等门禁、中间数据终结和 approved 默认导出契约

- 状态：已关闭 / 自动验收通过（2026-07-27）
- 严重性：高
- 类型：ETL / SQLite / 来源追踪 / 导入导出 / 数据治理
- 对象或页面：`approve_import`、`source_references`、`import_jobs`、`staging_items`、`staging_relations`、`review_decisions`、导入摘要导出命令。
- 根因：审批缺少事务内状态门禁，来源证据未按完整定位键复用；中间表没有按 job 的受控终结流程；默认摘要选择器未限定 approved 状态。

- 数据边界：未清理历史重复来源引用，未改对象匹配、旧对象停用、Sheet 解析、源 Excel、正式 SQLite、真实用户库或打包产物。正式库只执行了只读 finalize dry-run，正式库与用户库哈希保持不变。
- 验证结果：基础 Python 与 MCP 虚拟环境定向生命周期测试均通过，覆盖重复/并发 approve、失败回滚、完整证据键复用、dry-run/apply/repeat/错误状态、恢复包状态漂移、正式库 CLI 写门禁和 latest-approved 导出；只读复审未发现剩余 P1/P2，判定可关闭。
- 关闭条件：重复与并发审批无二次写入、来源证据幂等、按 job 终结与恢复状态闭环、默认导出只选 approved、临时库和受保护边界验证通过，已满足。
