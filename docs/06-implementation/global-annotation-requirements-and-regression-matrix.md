# 全局批注需求与回归矩阵

日期：2026-06-05
状态：全局设计基线已固化
适用范围：`frontend/capability-browser/` 所有当前页面和后续新增页面。

本文是 `OI-128C` 之后批注模块的最高优先级需求入口。后续任何批注相关修改必须先对照本文，不得只修当前页面、当前 tab 或当前截图。

## 0. 基线固化状态

2026-06-05 用户已基本验收当前批注设计。当前版本作为 SAPD Wiki 全局批注设计基线固化，后续新增页面、重构页面或局部修复不得重新发明批注样式、抽屉行为、定位逻辑或锚点规则。

基线验收证据：

- 当前用户库 33 条保存批注真实 Chrome 严格回归 `33/33 pass`。
- 覆盖 L0 / L1 / L2 对象与行批注、能力关注点、ISO 标准框架值、`AT-6` 标准控制项、安全技术服务 / 模块 / 措施 chip、LC-AP、LC-DT、知识库字典、标准页和安全指南 / 幻灯片页。
- 覆盖常态视觉、定位视觉、点击页面后常态保留、值 / 行粒度、抽屉滚动保持、抽屉遮挡处理、同名值误高亮防护和普通态宽黄条防回归。

后续处理原则：

- 如果后续发现单点问题，按本基线做 bug fix，不重新设计整套批注模块。
- 新页面上线前必须按本文第 8 节页面矩阵和第 11 节新页面接入清单补齐锚点与回归。
- 任何为了让单页通过而绕过全局锚点契约、扩大选择器白名单、恢复宽黄条背景、用整行替代值级锚点的修改，都视为回归。

## 1. 问题结论

批注不是安全能力映射页的局部功能，而是 SAPD Wiki 的全局用户写入能力。当前多轮返工的核心原因不是单个 CSS 或 selector，而是缺少可执行的跨页面契约：

- 保存批注后，原始页面是否必须出现常驻提示，没有被逐页验收。
- 点击批注定位后，临时焦点高亮是否清晰、是否符合 Apple shell / Office Word 风格，没有被逐页验收。
- 行批注、值批注、页面批注、折叠目录批注的定位规则混在一起，导致有些页面退化为行批注，有些页面无高亮，有些页面高亮整片区域。
- 代码审计只证明“存在锚点属性”，不能证明“真实保存后可见、点击后能定位、被抽屉遮挡时能露出目标”。

因此后续批注模块必须按“需求契约 + 页面矩阵 + 真实交互回归”执行。

## 2. 全局设计原则

批注模块按 overlay 层治理：

- 基础知识库页面只负责展示业务数据，并暴露稳定可批注锚点。
- 批注层负责右键菜单、抽屉、保存、常驻提示、定位、遮挡处理、tooltip 和临时高亮。
- 移除或替换批注层时，不应影响原页面的导航、筛选、表格列宽、数据加载、复制和只读浏览。
- 页面组件不得各自实现批注业务逻辑；新增页面只需要接入共享锚点契约。

批注视觉遵循：

```text
Apple shell + Office Word-like comment ink + SAPD restrained Morandi
```

含义：

- 批注是审阅痕迹，不是业务对象的新语义色。
- 已保存批注必须可见，但不能压过对象本身的安全服务、模块、标准、环境等语义颜色。
- 点击定位必须明显，用户一眼能看出当前定位目标。
- 颜色必须在白色表格、浅蓝分组行、绿色模块 chip、蓝色服务 chip、sand 标准 chip、生命周期浅色区域上都可辨识。
- 不允许每个页面临时定义自己的批注色、抽屉宽度、右键菜单或高亮方式。

## 3. 批注对象与锚点类型

| 锚点类型 | 含义 | 创建入口 | 保存后常驻提示 | 点击定位提示 |
|---|---|---|---|---|
| 页面 | 对当前页面整体写批注 | 右侧抽屉默认输入框 | 右侧标签和抽屉清单显示数量 | 进入页面顶部，不高亮整页 |
| 对象 | 当前能力、标准、指南、生命周期对象 | 对象标题 / 对象卡片 / 当前对象上下文 | 对象标题或对象容器低噪声提示 | 定位到对象头部 |
| 行 | 表格中的一条业务记录 | 右键行或行选择 | 整行浅暖色提示 + 左侧细提示线 | 整行短时 Apple blue 焦点扫光 |
| 值 / 字段 | 单元格值、关系 chip、生命周期字段、标准控制项、指南值 | 右键具体值 / chip / 字段 | 只在具体值内部显示 Word-like 批注墨水 | 具体值短时焦点，不得高亮整行 |
| 单元格 / 区域 | 未来用于复杂矩阵单元格 | 选中单元格或区域 | 仅单元格范围提示 | 仅单元格范围焦点 |
| 关系 | 未来用于关系边或映射关系 | 关系对象入口 | 关系对象提示 | 定位到关系上下文 |

硬规则：

- 值批注不得只按显示文本定位第一个同名值。
- 值批注必须记录 route、view、子页面 / 目录、对象、tab、行列位置和目标文本 hash。
- 行级业务对象必须优先使用稳定 `data-annotation-target-ref` 锚点，旧坐标型 `table_row` 只作为兼容 fallback。
- 标准 / 框架、知识库字典、LC-AP / LC-DT 等页面不得把对象级批注伪装成字段值批注。
- 旧批注缺少上下文时，不得高亮所有同名值；只能打开页面并提示需要重新建立精确锚点。
- 行批注才允许整行高亮；值批注只高亮值本身。

## 4. 颜色与高亮基准

### 4.1 已保存批注常驻态

目的：告诉用户这里有批注，但不打断阅读。

值 / 字段常驻态：

- 使用类似 Office Word 的文字级批注墨水。
- 颜色为低饱和 warm yellow / annotation ink。
- 背景只跟随文字或 chip 内部内容自适应，不铺满整行、整列或整片矩阵区域。
- 不改变 chip 的业务语义色，不把绿色模块 chip、蓝色服务 chip、sand 标准 chip 改成统一黄色。
- 不使用数字角标、数量胶囊、粗外框、强紫色描边。

行常驻态：

- 使用极浅暖色行背景。
- 左侧可有细提示线。
- 不得大面积高饱和黄底。

页面常驻态：

- 只通过右侧标签数量和抽屉清单提示。
- 不高亮页面整体。

### 4.2 点击定位临时态

目的：用户点击批注卡片后，一眼看到跳到哪里。

值 / 字段定位态：

- 在常驻批注墨水基础上叠加 Apple blue 低噪声焦点。
- 焦点必须足够明显，不能只是一圈浅蓝边。
- 允许短时扫光、柔和发光或背景亮度脉冲。
- 不使用粗紫色外框，不使用纯蓝大块覆盖。
- 动画结束后回到常驻态。

行定位态：

- 整行出现短时 Apple blue 焦点扫光。
- 如果抽屉遮挡目标，定位前自动收起抽屉，或滚动到不被遮挡的位置。

页面定位态：

- 切换到目标页面即可。
- 不使用全页高亮。

### 4.3 不合格样式

以下都视为回归：

- 保存批注后原始页面没有任何常驻提示。
- 值批注只高亮整行、整块单元格或整片区域。
- 点击定位后看不出当前位置。
- 同名值全部被高亮。
- 标准页、知识库字典页、LC-AP / LC-DT 页各用不同批注色。
- 抽屉展开后遮挡目标，定位仍然停在遮挡后方。
- 长标题只依赖浏览器原生 `title`，没有 Apple shell 自定义气泡。

## 5. 右侧批注抽屉需求

抽屉是全局组件，不是页面局部控件。

统一需求：

- 默认收起为右侧窄浮动标签，只露出低噪声数量徽标，不显示 `批注 1` 这类拼接文案。
- 标签语义必须拆成“批注”和“当前页数量”两部分：视觉上使用 `批注` 标签 + 独立数量徽标，读屏语义使用“当前页 N 条批注”。
- 鼠标移动到右侧标签位置时，标签以半胶囊 / 侧耳形态平滑预展开，约露出标签主体的 `1/2` 到 `2/3`；鼠标移开后平滑收起隐藏。
- 预展开只能移动标签本身，不能露出批注抽屉面板或面板内容；抽屉展开后标签侧耳必须与面板边缘融合，不得像独立按钮一样漂浮分离。
- 抽屉完全展开后，外侧标签不得继续保持横向大胶囊形态，应退化为低噪声边缘控件或交由面板内“收起”按钮承担关闭动作。
- 预展开标签被点击时，批注抽屉完全展开；展开状态再次点击标签或点击收起按钮时，抽屉平滑收回。
- 展开后固定宽度，不因标题、编码、批注正文变宽。
- 浮在页面上方，不改变表格列宽和工作区布局。
- 打开 / 收起只改变自身 `transform`，动画约 `300ms` 到 `420ms`，不得瞬间跳变。
- 支持 `prefers-reduced-motion`。
- 头部只保留当前页数量、标题“批注”和紧凑锚点栏，不重复堆叠页面标题、对象标题和自动标签。
- 当前页显示一个批注清单，清单内包含页面、对象、行和值批注。
- 批注卡片默认折叠，折叠摘要顺序固定为：状态、批注序号、锚点类型、锚点值。
- 展开后显示创建 / 更新时间、正文、状态下拉、定位、编辑、删除。
- 操作顺序固定为 `定位 / 编辑 / 删除`。
- 修改状态、点击编辑、保存编辑、取消编辑后，不得自动收起卡片，不得跳回抽屉顶部。
- 切换 route、对象、tab、子页面后，抽屉默认收起。
- 有未保存草稿时，切换前必须显示“保存并切换 / 放弃并切换 / 继续编辑”。

## 6. 创建批注需求

页面整体批注：

- 用户直接在右侧抽屉输入框写入时，默认创建页面级批注。

行 / 值批注：

- 用户必须先右键或选择具体行、值、chip 或字段。
- 右键菜单使用 Apple shell 浮层样式，只显示必要动作，例如 `添加批注`。
- 创建后抽屉打开，锚点栏显示当前锚点。
- 保存后批注进入当前页清单，并在原始页面出现常驻提示。

禁止：

- 没有具体锚点时伪造值批注。
- 点击表格空白创建值批注。
- 行 / 值批注保存后只在抽屉里出现，原页面没有提示。

## 7. 定位需求

点击批注卡片 `定位` 时必须按以下顺序执行：

1. 根据 `page_route` 切换到目标页面。
2. 根据锚点中的 view 恢复主工作区，例如能力映射、环境映射、知识库、标准、指南、LC-AP、LC-DT。
3. 恢复页面内 tab、阶段、标准表、二级目录、幻灯片或当前对象。
4. 如果目标在折叠目录中，自动展开父级。
5. 如果目标在右侧抽屉覆盖范围内，先收起抽屉或滚动到可见位置。
6. 滚动到锚点。
7. 播放与锚点类型匹配的临时高亮。

验收必须分别证明：

- 同页定位可用。
- 跨 tab 定位可用。
- 跨子页面 / 子目录定位可用。
- 折叠目录定位可用。
- 抽屉遮挡时能露出目标。
- 同名值不会误定位。

## 9. 验收分层

### 9.1 代码契约

必须通过：

```bash
node scripts/audit_user_annotation_contract.mjs
```

该脚本至少检查：

- 统一值锚点选择器。
- 普通 `td` 值级兜底。
- 稳定 `data-annotation-target-ref` overlay 锚点。
- 知识库表格行渲染后能获得对象级稳定锚点。
- 行级高亮能穿透到 `td` / `th`，不会被表格背景盖住。
- 共享 `relationChip` 自带批注值锚点。
- LC-AP / LC-DT 生命周期字段值锚点。
- 折叠目录定位恢复函数。
- 批注高亮 CSS 的常驻态与定位态。
- 本需求文档和全局设计基线是否包含强制条款。

### 9.2 渲染契约

必须检查代表组件渲染出的 HTML 中存在值级锚点，覆盖：

- 能力映射技术视角。
- 能力映射管理视角。
- 信息化环境。
- 知识库字典表格。
- 标准 / 框架表格。
- LC-AP。
- LC-DT。
- 详情面板 / 检查器。

### 9.3 真实交互契约

任何批注相关代码变更完成前，至少抽样真实交互检查：

- 保存一条页面批注。
- 保存一条行批注。
- 保存一条值批注。
- 刷新页面后常驻提示仍在。
- 点击批注卡片定位到目标。
- 抽屉遮挡目标时自动收起或露出目标。
- 修改状态 / 编辑批注后卡片不跳回顶部。
- 删除批注后原页面提示消失。

由于系统 Chrome 曾在本项目中崩溃，默认不强制每轮启动系统 Chrome。若需要截图级证明，优先使用 Codex in-app Browser 或经用户确认后串行执行 `--allow-system-chrome`，不得并行打开多个系统 Chrome 回归。

## 11. 新页面接入清单

后续新增页面、重构页面或新增复杂组件时，必须先完成本清单，再进入人工验收。不得等用户截图反馈后再临时补锚点。

### 11.1 页面对象声明

- 页面必须有稳定 `page_route`，并能通过主导航或 route 恢复。
- 页面整体必须能创建页面级批注。
- 页面如有当前对象、当前 tab、当前子目录、当前幻灯片、当前标准表或当前生命周期阶段，保存批注时必须记录这些上下文。
- 切回页面时必须能恢复到同一对象 / tab / 子页 / 幻灯片，而不是只回到 route 顶部。

### 11.2 锚点声明

- 对象级目标使用稳定 `data-annotation-target-ref`。
- 值级目标使用 `data-annotation-value="true"` 和 `data-copy-text`。
- 共享关系 chip 必须继续使用 `display.annotationValueAttrs` 或等价共享 helper。
- 普通业务 `td` 作为兜底值锚点；表头、空值、`/`、`暂无`、`待补充` 不创建值批注。
- 指南 / 幻灯片页必须为每个 slide stage 或可审阅页面区域提供稳定锚点。
- 如果存在折叠分组、虚拟列表、懒加载标准表或按需 projection，定位前必须先加载 / 展开目标所在上下文。

### 11.3 视觉接入

- 常态值批注使用文字级琥珀批注墨水，不铺满整行、整列或整片矩阵。
- 定位态使用 Apple blue 焦点，不使用强紫色描边、整块黄底或角标。
- 业务 chip 保留自己的语义色，只叠加低噪声批注提示。
- 行批注才允许整行提示；值批注只提示具体值。
- 右侧抽屉打开时不得改变主布局列宽；定位被遮挡时必须露出目标。

### 11.4 回归准入

新增页面至少需要覆盖：

- 页面批注保存后可见于抽屉清单。
- 行或对象批注保存后常态高亮可见。
- 值批注保存后只高亮值本身。
- 跨 route / tab / 子页 / 幻灯片定位可恢复上下文。
- 点击页面其他位置后，常态高亮仍保留。
- 无批注对象不出现误高亮。

必须执行：

```bash
node scripts/audit_user_annotation_contract.mjs
git diff --check
```

若该页面已有用户保存批注，或本轮改动涉及批注定位 / 视觉 / 抽屉 / 锚点解析，还必须执行真实浏览器保存批注回归：

```bash
node scripts/audit_saved_user_annotations.mjs --url http://127.0.0.1:5173 --allow-system-chrome --width 1800 --height 1200 --compact
```

## 12. 维护边界

批注基线后续只允许做三类变更：

- Bug fix：某个页面锚点、定位、视觉或抽屉状态未满足本文契约。
- Coverage：新增页面或新增组件按第 11 节接入。
- Governance：补充脚本、文档或回归矩阵，减少未来返工。

不建议做：

- 在未拆出独立组件前继续扩大 `app.js` 中批注业务逻辑。
- 为单页新增私有批注样式或私有定位分支。
- 在 `OI-128C` checkpoint 前混入工作台总览、数据篮、导出、能力重组或用户库治理。
