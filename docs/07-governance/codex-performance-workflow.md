# Codex 轻量开发与验证工作流

> 当前执行权威为仓库根 `AGENTS.md`。本文只补充 SAPD 的性能路由，不重复授权、数据边界、交接包或发布规则。

## 目标

在不降低正确性的前提下，减少无效上下文、模型往返、插件启动、重复验证和长工具等待。多会话不是默认并行机制；当前任务内并行由父 Agent 编排内部子 Agent。

## 快速路径

1. 读取最近的 `AGENTS.md`、目标 owner 和最小相关测试或契约。
2. 先判断是单 owner 小修，还是存在两个以上可独立推进的实质工作流。
3. 小修由父 Agent 直接完成：一次聚焦检查、一个最小补丁、一次定向验证，然后停止。
4. 复杂任务先确定关键路径、接口和合并态验收，再把非阻塞 sidecar 或不重叠代码片交给内部子 Agent。
5. 只有证据跨越数据、API、用户状态、对象粒度、App、打包、发布或安全边界时，才扩大读取、Skill 和测试范围。

不要默认读取归档、完整历史、大型 JSON、导出目录、数据库备份、全量 diff、完整 DOM、长 console log 或全量进程列表。优先摘要和计数，异常后再深入。

## 根因与定向验收

用户样例是首个黄金样例，不等于只能修截图表面。先确认控制现象的共享 owner：

- 局部问题只修局部 owner；
- 共性问题只修共享 owner，不在多个页面堆重复补丁；
- 发现数据、API、用户状态、对象粒度或发布边界时，按对应契约升级。

普通 UI 修复默认验证黄金样例、必要的同 owner 代表样例和一个边界反例。只有响应式问题才扩展多个视口；只有 durable contract 变化才同步设计或业务规格。

## 子 Agent 路由

父 Agent 保留立即阻塞的关键路径，并只委派能够并行产生价值的工作。每个子任务包只包含：

```text
目标与输入：
只读或精确 write set：
依赖与禁止范围：
验收证据：
超时、最多一次重试和停止条件：
返回格式：结论、改动文件、验证、剩余风险
```

编码 write set 必须互斥。默认使用新鲜、最小上下文；父 Agent 不重复子任务，不靠高频 `wait_agent` 消耗时间，并在最终 workspace 统一集成和验收。

Product Design、调研和审查适合作为只读 sidecar。规格确定后再实施；不得和实现 Agent 同时写生产 owner。

## 慢任务诊断

先识别当前层，再处理：

| 现象 | 判断证据 | 恢复 |
|---|---|---|
| 模型仍在推进 | reasoning、token 或事件继续增长 | 不重复启动工作；继续父 Agent 的非重叠任务 |
| 命令仍在运行 | 进程、日志或产物变化 | 使用有界等待，不做高频轮询 |
| 等待审批或用户输入 | 明确 pending 状态 | 说明所需决定和影响 |
| 工具挂起 | 超过自身 timeout 且无 output | 内部子 Agent 中断或关闭后缩小范围重试一次 |
| 上下文压力 | 多次 compaction、每轮重放显著增长 | 尽快完成当前闭环；需要时提出精简 handoff |
| 并发写入 | 同 checkout 或同 file set 被多个 writer 修改 | 立即停止一个写入路径或迁移到隔离 workspace |

高挂起风险的文件选择器、浏览器上传、长测试矩阵和打包检查，若不在立即关键路径，优先交给内部子 Agent，保证父 Agent 仍可响应和恢复。

## 验证层级

- 小修：目标语法或静态检查，加一次目标路由的批量 DOM/浏览器验收。
- 跨模块：受影响契约、模块测试和最终合并态集成验证。
- 数据、用户状态、App 或发布：调用对应 SAPD Skill 和验收矩阵；5173 不替代 DMG Runtime。

验证失败先判断是否属于当前 write set。其他活动改动造成的失败单独报告，不越权修改。

## 停止与报告

满足当前验收且没有新的材料性边界后立即停止。最终只报告结果、改动范围、影响面、验证和剩余风险；不为已闭环的小修新增状态文档、Open Issue 或设计规格。
