## 2. 五级统一语义（业务定义的 V3 评审投影）

以下判定锚点用于审阅 V3 具体评分内容；规范业务语义仍以业务设计为准。

| 等级 | 名称 | 统一判定锚点 |
|---|---|---|
| L1 | 非正式执行 | 尚未形成受控、可重复的能力；活动可能缺失，或仅局部、临时、依赖个人经验开展。 |
| L2 | 计划跟踪 | 明确负责人、范围、计划、频率和资源，能够记录并跟踪执行状态，但尚未组织统一。 |
| L3 | 充分定义 | 正式制度、标准、职责和程序明确，在适用范围内一致、可重复执行，具备例外和变更机制。 |
| L4 | 量化控制 | 能力稳定运行并形成可跨周期比较的结果；依据批准的控制目标、质量要求、时限、容忍边界或验证结果识别偏差，纠正并验证效果，不预设候选指标。 |
| L5 | 持续优化 | 在稳定 L4 基础上，由趋势、根因、复发问题或外部变化触发改进，验证前后效果并将有效改进固化；AI/ML 不是判据。 |

### Level 5 最低判定门槛

只有同时满足以下条件才可评为 L5：已有稳定 L4 基础；改进由趋势、根因、复发问题或外部变化触发；改进目标明确；实施结果经过验证；能够比较改进前后效果；有效改进已固化到制度、流程、配置或知识中。仅做一般整改、工具升级或规则调整，最高仍为 L4。

### 自定义模板通用评分依据

以下内容是业务设计规范定义在 V3 审阅包中的评审投影，不另立一套业务语义。自定义模板从基础模板复制的评估点继续保留对象专用评分依据。只有用户新建且没有对象专用评分依据的评估点，才使用以下 L1—L5 通用描述及配套四维通用 Rubric；不得复制其他评估点的对象专用文字，也不得借此自动修复固定模板的 Rubric 缺失。

| 等级 | 自定义模板通用描述 |
|---|---|
| L1 非正式执行 | 已开展相关活动，但依赖个人经验或临时安排，范围、方法与证据不稳定。 |
| L2 计划跟踪 | 已明确责任、范围和计划并跟踪重点任务，但跨团队标准和执行一致性不足。 |
| L3 充分定义 | 职责、流程、支撑机制和记录已正式定义，并在适用范围一致执行，例外与变更受控。 |
| L4 量化控制 | 能力稳定运行，结果可跨周期比较，并依据批准目标或控制边界识别偏差、纠正并验证效果。 |
| L5 持续优化 | 基于稳定的 L4 证据、趋势、根因或外部变化持续改进，比较前后效果并固化有效做法。 |

|---|---|---|
| ARS-001 | 拆为 ARS-V3-001A/B/C | 架构设计、冗余高可用、可靠性恢复对应不同安全结果。 |
