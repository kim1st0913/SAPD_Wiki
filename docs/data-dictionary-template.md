# 数据字典模板

这份模板用于在开发前确定字段。初期不追求完美，先从样例文件中提取候选字段，再逐步稳定。

## 1. 知识对象类型清单

| 类型编码 | 类型名称 | 说明 | 第一批是否启用 | 示例 |
|---|---|---|---|---|
| methodology | 方法论 | 框架、原则、方法、模型 | 是 | 零信任方法论 |
| capability | 能力项 | 可建设、可评估、可复用的能力 | 是 | 资产识别能力 |
| control | 控制措施 | 安全、管理、流程控制动作 | 是 | 日志审计 |
| process | 流程步骤 | 有先后顺序的工作步骤 | 待定 | 漏洞处置流程 |
| risk | 风险项 | 威胁、漏洞、攻击路径、业务影响 | 是 | 未授权访问 |
| indicator | 指标项 | 评估指标或度量项 | 是 | 平均响应时间 |
| assessment_result | 评估结果 | 某次评估的当前值和目标值 | 待定 | 当前得分 3 |
| improvement_task | 改进任务 | 根据评估结果形成的改进建议 | 待定 | 建立资产台账 |
| case | 案例 | 项目、行业、事件案例 | 待定 | 某行业安全建设案例 |
| architecture_element | 架构元素 | 系统、应用、组件、接口 | 待定 | IAM 系统 |
| term | 术语 | 缩写、定义、概念 | 待定 | SOAR |

## 10. 字段进入 V1 的判断标准

字段满足以下任意两条，才建议进入 V1：

- 至少 2 个样例文件中出现；
- 用户明确会用它筛选或搜索；
- 用户明确会导出它；
- 它用于来源追踪、版本或更新判断；
- 没有它就无法区分两条知识。

不满足的字段可以先放进 `metadata_json`，后续稳定后再提升为正式字段。
